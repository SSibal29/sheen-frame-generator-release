# Sheen Frame Generator — releases

휘도감 프레임 만들기(Sheen Frame Generator)의 배포판과 업데이트 관리 파일입니다.

- **Releases** — 실행 파일판 zip. 압축을 풀고 `SheenFrameGenerator.exe` 를 실행합니다 (설치 · 로그인 필요 없음).
- **control.json** — 프로그램이 켤 때 읽기만 하는 관리 파일 (새 버전 · 이용 상태). 프로그램은 PC 의 정보를 보내지 않습니다.

---

Release builds and the update control file of Sheen Frame Generator. Download a zip from **Releases**, unzip it and run
`SheenFrameGenerator.exe` (no installation or login needed). The program only reads `control.json` at start-up and
sends no information about the PC.
